# Security Policy

## Scope

IntentKernel is currently a specification-first project with educational reference code. Treat all reference code as non-production.

## Reporting a Vulnerability

Please open a private security advisory or contact repository maintainers before public disclosure when possible.

Include:

- affected file/spec section
- impact summary
- reproduction or proof-of-concept details
- suggested mitigation

## Response Expectations

- Initial triage acknowledgement target: 5 business days
- Follow-up status updates as investigation progresses

## Coordinated Disclosure

We prefer coordinated disclosure and will credit reporters unless anonymity is requested.
